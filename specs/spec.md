# Spec: ฟีเจอร์แจ้งเตือนสต็อกต่ำของ RAM, ฟีเจอร์ค้นหา RAM, จัดการสต็อก, ปรึกษาผู้เชี่ยวชาญ และข้อมูล RAM เชิงลึก

## 1. เป้าหมาย (Goal)
เพิ่มความสามารถให้ระบบร้านขายอุปกรณ์คอมพิวเตอร์รองรับการค้นหาและเลือกซื้อ RAM ได้สะดวกขึ้นสำหรับ `user` หลายประเภท โดยครอบคลุมตั้งแต่การค้นหา RAM ที่มี RGB และรองรับระบบ Sync ของเมนบอร์ด การตรวจสอบและตัดสต็อกด้วย Serial Number การส่งรูปภาพเพื่อขอคำแนะนำจากผู้เชี่ยวชาญ ไปจนถึงการกรอง RAM แบบ Kit และการแสดงข้อมูลเชิงลึกสำหรับ `user` ที่ต้องการนำไปใช้ในการ Overclock

เป้าหมายหลักของระบบคือ

1. ให้ `user` สามารถค้นหา RAM ตามคุณสมบัติที่ต้องการได้อย่างแม่นยำ
2. ให้ `user` ตรวจสอบความเข้ากันได้ของ RGB Sync กับระบบของเมนบอร์ดได้
3. ให้พนักงานสามารถตัดสต็อก RAM จากการขายหน้าร้านได้ทันทีด้วย Serial Number
4. ทำให้จำนวนสต็อกบนระบบออนไลน์และหน้าร้านสอดคล้องกัน
5. ให้ `user` ที่ไม่เชี่ยวชาญด้านคอมพิวเตอร์สามารถส่งรูป RAM เดิมเพื่อขอคำแนะนำได้
6. ให้ `user` สามารถกรอง RAM แบบ Kit ที่เหมาะกับการใช้งานประสิทธิภาพสูง
7. ให้ `user` ระดับโปรสามารถดูข้อมูล RAM เชิงลึก เช่น Timing, Voltage และ Memory Chip ได้
   
## 2. User Story
| รหัส | User Story |
|---|---|
| US-01 | As a `user`, I want กรองหา RAM ที่มีไฟ RGB และตรวจสอบระบบ RGB Sync ที่รองรับ เพื่อให้สามารถเลือก RAM ที่เข้ากับระบบไฟของเมนบอร์ดได้ |
| US-02 | As a `user`, I want สแกน Serial Number ของ RAM ที่ขายหน้าร้านเพื่อตัดสต็อกทันที เพื่อให้จำนวนสต็อกในระบบตรงกับสินค้าจริง |
| US-03 | As a `user`, I want ส่งรูป RAM เดิมผ่านระบบแชท เพื่อให้ได้รับคำแนะนำในการเลือก RAM ที่ถูกต้อง |
| US-04 | As a `user`, I want กรอง RAM แบบ Kit of 2 หรือ Kit of 4 ที่มีความจุรวมตั้งแต่ 64GB ขึ้นไป เพื่อให้สามารถเลือก RAM สำหรับงานประสิทธิภาพสูงได้ |
| US-05 | As a `user`, I want ดูข้อมูล RAM เชิงลึก เช่น Timing, Voltage และชนิดของ Memory Chip เพื่อให้สามารถประเมิน RAM ก่อนซื้อหรือใช้งาน Overclock ได้ |

## 3. Acceptance Criteria (Given-When-Then)
## US-01: ค้นหา RAM ที่รองรับ RGB Sync

### Scenario 1: กรอง RAM ด้วย RGB Sync และ ASUS

```gherkin
Scenario: ค้นหา RAM ที่รองรับ ASUS Aura Sync
  Given user อยู่ในหน้าค้นหาสินค้า RAM
  When user ติ๊กเลือกฟิลเตอร์ "RGB Sync"
  And user เลือกแบรนด์ "ASUS"
  Then ระบบจะแสดงเฉพาะสินค้า RAM ที่มีไฟ RGB
  And ระบบจะแสดงเฉพาะสินค้า RAM ที่มีสัญลักษณ์รองรับ ASUS Aura Syncำ

Scenario: จ่ายสินค้าโดยสต็อกยังสูงกว่า threshold
  Given สินค้า "สายไฟ 2.5 sq.mm" มีสต็อก 50 เมตร และ threshold = 15
  When พนักงานบันทึกจ่ายออก 10 เมตร
  Then สต็อกคงเหลือ 40 เมตร
  And ระบบไม่ส่งการแจ้งเตือน
```
### AC ของ US-01 และ US-03
(เติมเอง อย่างน้อย 2 scenario ต่อ story)

## 4. In Scope / Out of Scope
**In Scope:** บันทึกรับ/จ่าย + อัปเดตสต็อกใน memory, แจ้งเตือน email/sms (print แทนส่งจริง), รายงานมูลค่าแยกหมวด
**Out of Scope:** ส่ง email/sms จริง, ระบบ login/สิทธิ์, ฐานข้อมูลถาวร (เติมเอง: ระบุว่าทำหรือไม่)
