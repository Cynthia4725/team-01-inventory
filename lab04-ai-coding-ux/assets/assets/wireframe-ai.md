# Text Wireframes (ASCII Layout) - Inventory Management System

---

## 1. Login Page

**กลุ่มผู้ใช้:** เจ้าหน้าที่คลังสินค้าและพนักงานทั่วไป ทักษะเทคโนโลยีระดับเริ่มต้น–ปานกลาง (เน้นความเรียบง่าย ชัดเจน ไม่ซับซ้อน)

### Layout (Default & Structure)
```text
+-----------------------------------------------------------------------+
|                       ระบบจัดการคลังสินค้า (INVENTORY)                   |
+-----------------------------------------------------------------------+
|                                                                       |
|                          [ เข้าสู่ระบบ ]                              |
|                                                                       |
|  ชื่อผู้ใช้งาน (Username) *                                           |
|  +-----------------------------------------------------------------+  |
|  | admin_user                                                      |  |
|  +-----------------------------------------------------------------+  |
|                                                                       |
|  รหัสผ่าน (Password) *                                                |
|  +-----------------------------------------------------------------+  |
|  | **********                                                      |  |
|  +-----------------------------------------------------------------+  |
|                                                                       |
|  [X] จดจำการเข้าสู่ระบบไว้ในอุปกรณ์นี้                                 |
|                                                                       |
|  [  เข้าสู่ระบบ (Primary)  ]             [ ล้างข้อมูล (Secondary) ]    |
|                                                                       |
+-----------------------------------------------------------------------+

คำอธิบายการออกแบบตามหลัก Usability & Accessibility
Visible Labels: มีป้ายกำกับด้านบนช่องกรอกทุกช่อง พร้อมสัญลักษณ์ * ระบุชัดเจนว่าต้องกรอก ไม่พึ่งพาเพียงแค่ Placeholder เพื่อให้อ่านเข้าใจง่ายแม้ระบบจำค่าเดิมไว้

Actionable Error Messages: ข้อความแจ้งเตือนใต้ช่องกรอกบอกวิธีแก้ไขทันที เช่น "รหัสผ่านต้องมีความยาวอย่างน้อย 8 ตัวอักษร" ไม่ใช่แค่เตือนว่า "ผิดพลาด"

Button Placement: วางปุ่มหลัก (เข้าสู่ระบบ) ไว้ทางซ้ายตามแนวสายตา และใช้สี/กรอบเด่นกว่าปุ่มรอง
