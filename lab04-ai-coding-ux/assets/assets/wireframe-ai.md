# AI Text Wireframe

## Persona ที่ใช้ในการออกแบบ

**นัท — พนักงานคลังสินค้า**

* อายุ: 25 ปี
* ตำแหน่ง: พนักงานคลังสินค้า
* ประสบการณ์: ทำงานด้านคลังสินค้า 2 ปี
* อุปกรณ์หลัก: Smartphone และคอมพิวเตอร์ Windows
* ทักษะเทคโนโลยี: 3/5

**เป้าหมายหลัก:** ตรวจสอบจำนวนสินค้าได้รวดเร็ว และบันทึกการรับเข้า/เบิกสินค้าได้ถูกต้องโดยไม่ต้องกรอกข้อมูลซ้ำหลายรอบ

**Pain points:** ค้นหาสินค้าจำนวนมากยาก, การกรอกข้อมูลหลายช่องทำให้ผิดพลาดง่าย และข้อมูลสินค้าอาจไม่เป็นปัจจุบัน

# 1. Login

```text
+------------------------------------------------+
|              INVENTORY SYSTEM                  |
|                                                |
|              เข้าสู่ระบบ                      |
|                                                |
|  ชื่อผู้ใช้ *                                  |
|  [________________________________]            |
|                                                |
|  รหัสผ่าน *                                    |
|  [________________________________]            |
|                                                |
|  [ ] จดจำการเข้าสู่ระบบ                       |
|                                                |
|             [ เข้าสู่ระบบ ]                   |
|                                                |
|  ลืมรหัสผ่าน?                                  |
|                                                |
|  [ตัวอย่าง Error]                              |
|  ! รหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบอีกครั้ง     |
|                                                |
+------------------------------------------------+
```

### Usability

* ใช้ฟอร์มสั้น มีเฉพาะข้อมูลที่จำเป็น ลดการกรอกซ้ำ
* ปุ่ม **เข้าสู่ระบบ** เป็นปุ่มหลักและอยู่ใต้ฟิลด์ทันที ทำให้ผู้ใช้ 3/5 เข้าใจลำดับการใช้งานง่าย
* มีข้อความ Error ใต้ฟอร์มเพื่อให้ผู้ใช้รู้ว่าต้องตรวจสอบรหัสผ่าน
* ใช้ label ที่มองเห็นได้ชัดเจน ไม่ใช้ placeholder แทน label
* รองรับทั้งคอมพิวเตอร์ Windows และ Smartphone ด้วยการจัดวางองค์ประกอบเป็นแนวตั้ง

### Accessibility

* ทุกฟิลด์มี label ที่มองเห็นได้
* ช่องที่จำเป็นต้องกรอกมีเครื่องหมาย `*`
* Error อธิบายแนวทางแก้ไข ไม่ใช้เพียงข้อความว่า "เกิดข้อผิดพลาด"

### Success State

```text
! เข้าสู่ระบบสำเร็จ กำลังนำไปยัง Dashboard...
```

# 2. Dashboard

```text
+----------------------------------------------------------------+
| INVENTORY SYSTEM                         [นัท] [ออกจากระบบ]    |
+----------------------------------------------------------------+
|                                                                |
| Dashboard                                                      |
|                                                                |
| [ ค้นหาสินค้า: __________________________ ] [ค้นหา]            |
|                                                                |
| +----------------+ +----------------+ +----------------------+ |
| | สินค้าทั้งหมด  | | สินค้าใกล้หมด  | | รายการวันนี้         | |
| |      128       | |       8        | |        24            | |
| +----------------+ +----------------+ +----------------------+ |
|                                                                |
| สินค้าในคลัง                                                   |
|                                                                |
| +------------------------------------------------------------+ |
| | รหัส     | ชื่อสินค้า       | คงเหลือ | สถานะ              | |
| +------------------------------------------------------------+ |
| | P001     | Keyboard         | 25       | ปกติ               | |
| | P002     | Mouse            | 5        | ใกล้หมด            | |
| | P003     | USB Cable        | 0        | สินค้าหมด          | |
| +------------------------------------------------------------+ |
|                                                                |
| [ + รับสินค้าเข้า ]              [ - เบิกสินค้า ]              |
|                                                                |
| อัปเดตล่าสุด: 11/09/2026 13:30                                 |
+----------------------------------------------------------------+
```

### Usability

* มี **Search** อยู่ด้านบน เพราะ Persona ระบุว่าการค้นหาสินค้าจำนวนมากเป็นปัญหาหลัก
* แสดงจำนวนสินค้าและสถานะสำคัญทันที โดยไม่ต้องเปิดหลายหน้า
* แสดงสถานะ `ปกติ / ใกล้หมด / สินค้าหมด` เพื่อช่วยตัดสินใจได้รวดเร็ว
* ปุ่ม **รับสินค้าเข้า** และ **เบิกสินค้า** เป็น Action หลักที่เข้าถึงได้จาก Dashboard โดยตรง ลดจำนวนขั้นตอน
* แสดงเวลาอัปเดตล่าสุดเพื่อช่วยให้ผู้ใช้ประเมินว่าข้อมูลเป็นปัจจุบันหรือไม่

### Accessibility

* ใช้ข้อความระบุสถานะร่วมกับการแสดงผล ไม่พึ่งพาสีเพียงอย่างเดียว
* Search มี label ที่ชัดเจน
* ปุ่มมีข้อความบอกหน้าที่ ไม่ใช้ icon อย่างเดียว
* ตารางมีหัวคอลัมน์ชัดเจน

### Validation / Error State

```text
ค้นหาสินค้า: [____________________________] [ค้นหา]

ไม่พบสินค้าที่ค้นหา
ลองตรวจสอบรหัสสินค้า หรือชื่อสินค้า แล้วค้นหาอีกครั้ง
```

### Success State

```text
✓ บันทึกข้อมูลสำเร็จ
ข้อมูลสินค้าได้รับการอัปเดตแล้ว
```

### Usability

* มีเฉพาะข้อมูลที่จำเป็นต่อการสร้างสินค้า เพื่อลดการกรอกหลายช่อง
* ฟิลด์บังคับใช้ `*` เพื่อให้ผู้ใช้รู้ว่าต้องกรอกอะไร
* ใช้ Dropdown สำหรับหมวดหมู่และหน่วยสินค้า ลดการพิมพ์และลดข้อมูลไม่ตรงรูปแบบ
* ปุ่ม **บันทึกสินค้า** เป็นปุ่มหลัก อยู่ด้านขวาและแยกจาก **ยกเลิก** เพื่อป้องกันการกดผิด
* Validation แสดงใกล้กับฟิลด์ที่ผิด เพื่อให้ผู้ใช้รู้ว่าต้องแก้ตรงไหน

### Accessibility

* ทุกฟิลด์มี visible label
* ไม่ใช้ placeholder เป็น label
* Error อธิบายวิธีแก้ เช่น "ต้องเป็นตัวเลข 0 หรือมากกว่า"
* สามารถใช้งานด้วย keyboard ได้โดยเรียงลำดับจากบนลงล่าง

## สรุปหลักการออกแบบ

Wireframe ทั้ง 3 หน้ายึดตาม Persona "นัท" โดยเน้น

1. **ลดการกรอกข้อมูลที่ไม่จำเป็น** เพราะผู้ใช้ไม่ต้องการกรอกข้อมูลซ้ำหลายรอบ
2. **ค้นหาได้เร็ว** โดยให้ Search อยู่ในตำแหน่งที่เห็นได้ง่ายบน Dashboard
3. **แสดงข้อมูลสำคัญทันที** เช่น จำนวนคงเหลือและสถานะสินค้า
4. **ลดความผิดพลาดในการกรอกข้อมูล** ด้วย validation และ dropdown
5. **แจ้ง Error พร้อมวิธีแก้ไข** ไม่ใช่เพียงแจ้งว่าเกิดข้อผิดพลาด
6. **แสดง Success State หลังบันทึก** เพื่อให้ผู้ใช้มั่นใจว่าข้อมูลถูกบันทึกแล้ว
7. **รองรับผู้ใช้ทักษะเทคโนโลยีระดับ 3/5** ด้วยปุ่มและ label ที่ชัดเจน และลดขั้นตอนที่ไม่จำเป็น
